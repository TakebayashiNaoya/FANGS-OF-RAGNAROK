# FANGS OF RAGNAROK

北欧神話を世界観とした3Dアクションゲーム。DirectX 12 + C++20で自作するエンジン(FangEngine)の上に作る。

- 対応プラットフォーム: Windows (x64) / Xbox One
- 開発環境: Visual Studio 2026

## 動作に必要な環境

- Windows 10 / 11(64bit)
- DirectX 12に対応したGPU

## 遊び方

[Releases](https://github.com/TakebayashiNaoya/FANGS-OF-RAGNAROK/releases/tag/rom-latest)から`FangsOfRagnarok-rom.zip`をダウンロードし、展開した`FangEngine.exe`を起動する。
