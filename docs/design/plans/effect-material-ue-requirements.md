# UE の材質の変換の要件

## 目的

材質の中の計算で見た目を作るエフェクト(斬撃など)を、自作エンジン(C++ / D3D12)で再現できるようにする。UE の材質(ノードグラフ)を HLSL に変換する。

## 決まっていること

| 項目 | 内容 |
|---|---|
| 対象 | UE 5.6 の Niagara のエフェクトの材質(Unlit) |
| 試す素材 | Fab の Niagara Slash(UE Game Work、AI の使用を許可)の `NE_attack01`〜`05` |
| 変換ツール | UE 側の記録ツールに足す |
| エンジン側の再生処理と、材質の入力の形 | エンジン側で決めて書く |

## 成功条件

- 斬撃の材質が HLSL に変換され、Unity で描いた斬撃が UE の見た目と近い(形・明るさ・消え方)
- エンジン側が呼ぶ関数と入力の形が文書になっている

## やらないこと

- ライティングのある材質、屈折・歪み、材質関数
- エンジン側の再生処理

## 制約

- 設計は最低限にする。端のケースは実装中に起きてから直す
- コードは短く素朴に書く。面接でユーザーが説明できること
