# UE側のエフェクト記録ツールの要件

## 目的

UE(Niagara)のストアのエフェクトを、Unity側の記録ツールと同じ形式(`.fxrec`)で記録し、自作エンジン(C++ / D3D12)で再生できるようにする。

## 決まっていること

| 項目 | 内容 |
|---|---|
| UE | 5.6(インストール済み) |
| 書き出す形式 | Unity側と同じ`.fxrec` version 2(`docs/design/plans/effect-recorder.md`の2節) |
| 記録ツール | Unity側とは別のprivateリポジトリに作る |
| エンジン側の再生処理 | 今回は作らない |
| 試す素材 | まずUEに入っているNiagaraのテンプレート。次にEpicの無料サンプル(Content Examples) |

## 成功条件

- Niagaraのエフェクトを1つ記録し、`.fxrec`のJSON・bin・テクスチャが出る
- 粒子の位置・大きさ・色などが、Sim Cacheの値と一致する
- Unityの確認用再生で描いたとき、UEで見た形・動きと合う

## やらないこと

- 材質(UEのノードグラフ)の変換。次の段階で行う
- Ribbon Renderer、GPUで動くエミッター
- エンジン側の再生処理

## 制約

- 設計は最低限にする。端のケースは実装中に起きてから直す
- コードは短く素朴に書く。面接でユーザーが説明できること
