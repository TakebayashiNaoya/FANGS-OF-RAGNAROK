# UE 側のエフェクト記録ツールの要件

## 目的

UE(Niagara)のストアのエフェクトを、Unity 側の記録ツールと同じ形式(`.fxrec`)で記録し、自作エンジン(C++ / D3D12)で再生できるようにする。

## 決まっていること

| 項目 | 内容 |
|---|---|
| UE | 5.6(インストール済み) |
| 書き出す形式 | Unity 側と同じ `.fxrec` version 2(`docs/design/plans/effect-recorder.md` の 2 節) |
| 記録ツール | Unity 側とは別の private リポジトリに作る |
| エンジン側の再生処理 | 今回は作らない |
| 試す素材 | まず UE に入っている Niagara のテンプレート。次に Epic の無料サンプル(Content Examples) |

## 成功条件

- Niagara のエフェクトを 1 つ記録し、`.fxrec` の JSON・bin・テクスチャが出る
- 粒子の位置・大きさ・色などが、Sim Cache の値と一致する
- Unity の確認用再生で描いたとき、UE で見た形・動きと合う

## やらないこと

- 材質(UE のノードグラフ)の変換。次の段階で行う
- Ribbon Renderer、GPU で動くエミッター
- エンジン側の再生処理

## 制約

- 設計は最低限にする。端のケースは実装中に起きてから直す
- コードは短く素朴に書く。面接でユーザーが説明できること
